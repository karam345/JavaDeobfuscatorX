# AI disclosure

JavaDeobfuscatorX was developed with OpenAI Codex assistance. Codex wrote or edited implementation, tests, synthetic fixtures, documentation, skill instructions and release automation.

Validation uses Java 21 builds, differential fixtures, archive rejection cases, both decompilers and javac. Tests cover the scenarios they exercise. Third-party obfuscated programs can contain untested bytecode and language edge cases.

The project has no recorded independent human security audit.
